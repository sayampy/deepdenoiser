# Test media

Deterministic fixtures for manual denoise/mux testing. Generated by
`python3 scripts/generate_test_media.py` (requires numpy and ffmpeg).

| File | What it is | Use |
|---|---|---|
| `clean_speech.wav` | 8 s synthetic formant speech, 48 kHz mono 16-bit | Reference / "before" comparison |
| `noisy_speech.wav` | Same speech + pink noise at ~5 dB SNR | Main denoise input — listen for noise suppression between syllables |
| `noise_only.wav` | Just the noise bed | Sanity check that denoising attenuates it |
| `test_video.mp4` | 8 s 1280x720 H.264 + AAC color bars | Video mux / trim testing (already H.264, so no transcode needed) |

Push to a device or emulator with:

```sh
adb push test-media/noisy_speech.wav /sdcard/Download/
adb push test-media/test_video.mp4 /sdcard/Download/
```

Then pick the file from the app's Home screen (or share it to the app).
