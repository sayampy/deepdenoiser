# Test media

Deterministic fixtures for manual denoise/mux testing. Generated by
`python3 scripts/generate_test_media.py` (requires numpy and ffmpeg).

| File | What it is | Use |
|---|---|---|
| `clean_speech.wav` | 8 s synthetic formant speech, 48 kHz mono 16-bit | Reference / "before" comparison |
| `noisy_speech.wav` | Same speech + pink noise at ~5 dB SNR | Main denoise input — listen for noise suppression between syllables |
| `noise_only.wav` | Just the noise bed | Sanity check that denoising attenuates it |
| `test_video.mp4` | 8 s 1280x720 H.264 + AAC color bars | Video mux / trim testing (already H.264, so no transcode needed) |
| `short_noisy.wav` / `short_noisy.mp4` | 8 s speech + pink noise, limiter clipping | Short denoise / mux smoke test |
| `long_noisy.wav` / `long_noisy.mp4` | 60 s looping speech + pink noise, limiter clipping | Long-run stability, cache and passthrough smoke test |

Push to a device or emulator with:

```sh
adb push test-media/short_noisy.wav /sdcard/Download/
adb push test-media/long_noisy.wav /sdcard/Download/
adb push test-media/short_noisy.mp4 /sdcard/Download/
adb push test-media/long_noisy.mp4 /sdcard/Download/
```

Objective smoke check after exporting a denoised WAV (measure a silent gap
between synthetic speech bursts — lower is better):

```sh
ffmpeg -v error -i <denoised.wav> -af "atrim=0.2:0.5,astats=metadata=1" -f null -
```

Then pick the file from the app's Home screen (or share it to the app).
